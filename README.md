## Run logs

The "Run on LEGO Brick" button in VS Code also saves everything the program
prints in a log file in `logs/`, and uploads it to the `logs` folder on GitHub.

- Open this folder itself in VS Code (File > Open Folder).
- After pulling this for the first time, close the "Pybricks" terminal once
  (trash can icon). The button then opens a new one that saves logs.
- A run that saves a log starts with "Saving output to ...".

The files that do this are `tools/run_logged.py`, `tools/ide/` and
`.vscode/settings.json`.
